## 🤔 O que é o GitHub?

O GitHub é uma plataforma onde desenvolvedores guardam, organizam e compartilham código. Ele funciona em cima de uma ferramenta chamada **Git**, que controla as versões dos arquivos de um projeto — ou seja, guarda um histórico de tudo que já foi alterado.

Pense assim: é como o "Google Drive" dos programadores, só que com superpoderes para trabalhar em equipe.

<br/>

## 📚 Termos básicos que você vai ver por aí

| Termo | O que significa |
|---|---|
| **Repositório (repo)** | A pasta do projeto. É onde todos os arquivos e o histórico de alterações ficam guardados. |
| **Commit** | Um "salvamento" das alterações feitas, com uma mensagem explicando o que mudou. |
| **Branch** | Uma cópia paralela do projeto para testar algo novo sem bagunçar a versão principal. |
| **Pull Request (PR)** | Um pedido para juntar as alterações de uma branch com a principal — geralmente revisado por outras pessoas antes de aceitar. |
| **Issue** | Um card para reportar bugs, sugerir ideias ou organizar tarefas do projeto. |
| **Fork** | Uma cópia de um repositório de outra pessoa para o seu próprio perfil, para você poder mexer livremente. |
| **README** | O arquivo de apresentação de um repositório (ou do seu perfil, como este aqui!). |

<br/>

## 🛠️ Fluxo básico de trabalho

```
1. clone o repositório para o seu computador
   git clone https://github.com/usuario/repositorio.git

2. crie uma branch para sua alteração
   git checkout -b minha-alteracao

3. faça as mudanças e salve com um commit
   git add .
   git commit -m "explica o que foi feito"

4. envie a branch para o GitHub
   git push origin minha-alteracao

5. abra um Pull Request pedindo para juntar
   sua alteração ao projeto principal
```

<br/>

## ✨ Dica: este arquivo que você está lendo

Se você criar um repositório com o **mesmo nome do seu usuário** do GitHub (por exemplo, `usuario/usuario`), o `README.md` dele aparece automaticamente na página principal do seu perfil — como um cartão de visitas.

É exatamente esse tipo de arquivo que você está vendo agora. 🙂
